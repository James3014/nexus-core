# Nexus Verify Support

Status: G4A support-content source. A final HTTPS support URL is required before public submission.

## Product support

For Nexus Verify product questions or public-plugin issues, contact:

`james.chen.dev@gmail.com`

Do not send passwords, API keys, access tokens, MFA codes, private repository content, or other secrets.

When reporting an issue, include:

- the public GitHub repository owner/name and PR number, when relevant;
- the observed Nexus Verify result category;
- approximate time of the request;
- steps to reproduce without secrets.

## Security reports

For security vulnerabilities, use GitHub Private Vulnerability Reporting when available:

`https://github.com/James3014/nexus-core/security/advisories/new`

Do not disclose sensitive vulnerabilities in a public Issue.

## Expected handling

Support requests are triaged on a best-effort basis. This G4A package does not establish a paid support SLA.

The root `SECURITY.md` separately states the repository's security-response target.
